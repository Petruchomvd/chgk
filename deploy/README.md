# Развёртывание CHGK на личном сервере

Целевая схема:

- код: `/opt/chgk/current`;
- Python-окружение: `/opt/chgk/venv`;
- рабочие базы: `/var/lib/chgk/chgk_analysis.db` и `/var/lib/chgk/training.db`;
- переменные окружения: `/etc/chgk/chgk.env`;
- API: `127.0.0.1:8000`;
- веб-интерфейс до подключения домена: `127.0.0.1:8080` через SSH-туннель.

Базы никогда не размещаются внутри Git-клона. Перед переносом активной SQLite-базы
создаётся согласованный снимок средствами SQLite. После запуска сервер становится
основным местом хранения обеих баз, а Mac — местом проверенной резервной копии.

Службы:

- `chgk-api.service` — сайт и тренировки;
- `chgk-update.service` — безопасное обновление каталога;
- `chgk-update.timer` — ежедневный запуск обновления.

До подключения домена сайт открывается на Mac командой `chgktunnel`, после чего
доступен по адресу `http://127.0.0.1:8080`.

Публичный адрес сайта: `https://play.nordvel.ru`. HTTP перенаправляется на
HTTPS, запросы по одному IP-адресу без правильного имени отклоняются.
Сертификат Let's Encrypt продлевается системным таймером Certbot. Локальный
SSH-туннель остаётся запасным способом входа.

## Резервная копия на Mac

Скрипт `pull-backup-to-mac.sh` создаёт согласованные снимки обеих активных
SQLite-баз на сервере, переносит их в `~/Backups/myos/chgk`, проверяет
`PRAGMA quick_check` и сохраняет контрольные суммы. По умолчанию остаются
четыре последние еженедельные копии.

Файл `com.matvey.myos.chgk-backup.plist` запускает скрипт по воскресеньям
в 06:00 по локальному времени Mac. Если компьютер спит, macOS выполнит
пропущенный запуск после пробуждения.
